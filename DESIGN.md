# Editorial motion system

Audience: English explainer viewers at 1920×1080, 30 fps. The subject is how to
vet an AI SEO agency using the publisher's evidence. The video should make the
relationships and responsibilities in the narration visible.

Runtime token owner: `video/src/tokens.ts`. Pale lavender paper #E9E8F2, ink
#242139, violet #4739C7, near-white surface #FAF9FF and mint #B9E7D5. Slate
inverts the system. Arial heavy display type contrasts with regular takeaway
copy; no remote font dependency. Safe area80px, gap28px, radius12px. Text fits
both width and the available height. Anything under36px is a visible QA finding.

The opening is a publisher dossier. Methodology uses a connected process,
association network or responsibility map. Comparisons use paired fields.
Ranking uses ordered text rows without invented rank numbers or bars. Statistic
uses a dominant source phrase with smaller context panels, never inferred chart
values. Conclusion consolidates document requirements in a checklist.

Composition, primary node and draw/focus/cascade animation are validated named
choices. Each diagram label is an exact approved narration excerpt linked to
claims and original source IDs. The compiler derives reveal frames from the
matching Stage6 sentence. Process links encode order; association links encode
grouping, never causality. Card reveals accumulate; footer takeaways retain their
original screen cue bounds. A thin top track represents scene progress only.

No presentation-wide index numbers, decorative figures, invented labels, generated
React, raw model colors or unrelated stock imagery. Model selection is followed
by local editorial review. Offline plan revisions record their own input hash and
local-editorial provenance instead of pretending to be untouched model outputs.

Validation: exact-excerpt/cue tests, source preservation hashes, schema tests,
TypeScript/ESLint, bundle, representative Studio frames and QA stills. Visual
semantics and listening approval remain human judgments. Timing fallback findings
remain intact; a beautiful diagram cannot make approximate alignment exact.
